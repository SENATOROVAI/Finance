# Бухгалтерский учёт хозяйственных операций — Вариант 7

Учебная работа по бухгалтерскому учёту: журнал хозяйственных операций ООО за апрель, открытие Т-счетов, составление оборотно-сальдовой ведомости и бухгалтерского баланса.

Базовые суммы операций умножаются на коэффициент **k = 4,5** — это особенность варианта 7.

---

## Постановка задачи

На основании исходных остатков по счетам и журнала из 16 хозяйственных операций требуется:

1. Скорректировать суммы операций на коэффициент k = 4,5.
2. Составить **журнал хозяйственных операций** с проводками (Дт / Кт).
3. Открыть **Т-счета («самолётики»)** по всем используемым синтетическим счетам, отразить начальные остатки, обороты и вывести конечное сальдо.
4. Сформировать **оборотно-сальдовую ведомость (ОСВ)** с проверкой равенства итогов.
5. Составить **бухгалтерский баланс** на начало и на конец периода.
6. Определить **финансовый результат** от продажи продукции за апрель.

## Методика решения

### 1. Корректировка сумм
Каждая базовая сумма из условия умножается на k = 4,5. Например, поступление материалов 18 660 руб. превращается в 83 970 руб.

### 2. Разноска по Т-счетам
Для каждого используемого счёта строится «самолётик»: слева — дебет, справа — кредит. Заносятся:
- начальное сальдо (Сн);
- обороты по соответствующей стороне с номерами операций из журнала;
- итоговые обороты (ОД и ОК);
- конечное сальдо (Ск).

Конечное сальдо считается по правилу активного / пассивного счёта:
- **активный счёт:** Ск(Дт) = Сн(Дт) + ОД − ОК;
- **пассивный счёт:** Ск(Кт) = Сн(Кт) + ОК − ОД.

### 3. Оборотно-сальдовая ведомость
В ОСВ сводятся остатки и обороты по всем счетам. Должны выполняться три равенства:

- сумма дебетовых начальных сальдо = сумме кредитовых начальных сальдо;
- сумма оборотов по дебету = сумме оборотов по кредиту;
- сумма дебетовых конечных сальдо = сумме кредитовых конечных сальдо.

### 4. Баланс
По данным конечных сальдо ОСВ формируются разделы баланса:

- **Актив:** внеоборотные активы (01 − 02), запасы (10, 20, 43), денежные средства (50, 51), дебиторская задолженность (62, 71).
- **Пассив:** капитал и резервы (80, 99), краткосрочные обязательства (60, 69, 70).

Счёт 02 «Амортизация ОС» вычитается из счёта 01 (контрарный счёт).

- кредит 90 (выручка): 191 700,00 руб.
